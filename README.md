# EMAD-UI 🚀
> **A Futuristic Cyber-Dashboard Interface for Linux & Windows.**

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Electron](https://img.shields.io/badge/Electron-v39.5-68a063)
![React](https://img.shields.io/badge/React-v18-61dafb)

**EMAD-UI** is a high-performance, sci-fi inspired terminal interface designed for security enthusiasts and power users. It combines a retro-neon aesthetic with modern system monitoring and shell interaction.

---

## ✨ Key Features

- 🖥️ **Integrated Terminal:** Real-time command-line access with `node-pty`.
- 📡 **Network Radar:** Visual ping and network monitoring interface.
- 📁 **Cyber File Browser:** Navigate your system through a specialized HUD.
- 📊 **System Stats:** Live monitoring of CPU, Memory, and System performance.
- 🔊 **Immersive Audio:** Integrated mechanical key clicks and boot-up sound effects for a complete experience.
- 🎨 **Neon HUD Design:** Fully responsive, high-contrast UI built with Tailwind CSS.

   🪟 Windows (.exe)

🛠️ Development & Build Commands
If you want to contribute or build the project from source:

1. Installation
Bash
# Clone the repository
git clone [https://github.com/emadjawad/EMAD-UI.git](https://github.com/emadjawad/EMAD-UI.git)

# Install dependencies
npm install
2. Development Mode
Bash
npm run dev
3. Build for Production
Bash
# Build for Linux (AppImage & .deb)
npm run build:linux

# Build for Windows (Setup & Portable)
npm run build:win
